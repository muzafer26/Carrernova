## 1. THE ACTUAL STUDENT PROBLEM

A student completing Class 10 or Class 12 in Jammu & Kashmir faces severe uncertainty:

```
[CONFUSION] ──> [EXPLORATION] ──> [WHY ENGINE] ──> [DECISION WORKSPACE] ──> [OFFICIAL HANDOFF]
 "What next?"     Streams/Degrees  "Why this option?"  Side-by-side compare  Samarth/DSD/BOPEE
                  Skills/Govt Jobs Eligibility/Location Shortlist Persistence Official execution
```
