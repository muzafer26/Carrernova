## 1. KEY RETROSPECTIVE LESSONS

| Lesson ID | Mistake Identified | Root Cause | Reusable Process Rule |
|---|---|---|---|
| **LES-01** | Judging features by visual UI polish rather than student utility | Focus on visual aesthetics over student uncertainty reduction | **Rule:** Always evaluate feature utility against the 15 student decision questions before styling. |
| **LES-02** | Over-focusing on BCA / B.Com example degrees | Treating MVP sample data as the total student universe | **Rule:** Maintain a universal pathway taxonomy supporting 14+ academic faculties & 9 pathway families. |
| **LES-03** | Hiding ITI and vocational options inside degree cards | Assuming academic degree is the default root object | **Rule:** Build dedicated first-class routes (`/dashboard/skills`) for standalone non-degree pathways. |
| **LES-04** | Presenting govt jobs as generic text cards | Lack of backward educational mapping | **Rule:** Map backward stepping stones from the target career cadre to Class 10/12 prerequisites. |
| **LES-05** | Claiming test passes without CLI execution | Host Windows sandbox blocking CLI scripts | **Rule:** Distinguish `STATICALLY VERIFIED` vs `BLOCKED BY ENVIRONMENT` in audit reports. |
